# Simple Prompt Writing
## 1. List three programming languages

Here are three programming languages:

1. **Python** — known for its readable syntax and wide use in data science, AI, and scripting.
2. **Go** — a statically typed, compiled language built for simplicity and performance, especially in systems and backend development.
3. **Rust** — focused on memory safety and performance, popular for systems programming.

## 2. What are the benefits of Python for AI?

Python is particularly well-suited for AI development for several reasons:

**Simplicity and readability** — its clean syntax lets researchers and engineers focus on solving problems rather than wrestling with the language itself, making it easy to prototype and iterate quickly.

**Rich ecosystem of libraries** — tools like NumPy, Pandas, TensorFlow, PyTorch, and scikit-learn provide robust, battle-tested building blocks for everything from data manipulation to deep learning.

**Community and resources** — Python has one of the largest AI/ML communities, meaning abundant tutorials, research code shared in Python, and fast answers to problems.

**Interoperability** — it integrates well with lower-level languages like C and C++ under the hood (which is how libraries like NumPy achieve their speed), giving you both convenience and performance.

**Jupyter Notebooks** — the interactive notebook environment makes exploratory data analysis and model experimentation very natural, especially for research workflows.

**Industry adoption** — most AI research papers release their code in Python, and most AI-focused companies standardize on it, making it the de facto lingua franca of the field.

The main tradeoff is raw speed — Python is slow as an interpreted language — but in practice the heavy computation is offloaded to optimized C/C++/CUDA backends, so this rarely matters for AI workloads.
